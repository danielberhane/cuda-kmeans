Note the reduce kernel. reduce_cluster_changed launches a single thread block regardless of problem size, so it runs on one SM while the rest of the device idles. On the 2015 benchmarks it consumed 22% of per-iteration kernel time to move 0.5% of the bytes.

This page runs a JavaScript implementation matching the CUDA semantics exactly — first-K initialisation, squared float distance without sqrt, δ = changed/N convergence. It is verified against values measured from the real build (tools/verify-trace.mjs): 781 blocks, 1,904 bytes of shared memory, 31 iterations, and the full δ sequence. Timings shown are JavaScript on your CPU and are not GPU measurements — see the benchmarks for those.
